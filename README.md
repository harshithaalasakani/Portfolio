# Portfolio
🎯 My Personal Portfolio
A responsive and minimalistic portfolio showcasing my projects, skills, and resume. Built with HTML, CSS, and JavaScript.

🔗 Live Demo: https://harshithaalasakani.github.io/protfolio/

💡 Features:

Clean sectioned layout (About, Skills, Projects, Resume, Contact)

Project cards with GitHub and Live Demo links

Responsive design for all screen sizes

Smooth scrolling and scroll-to-top button

📁 Technologies Used:
HTML CSS JavaScript
